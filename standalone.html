Heads up: major sites like Google and YouTube send anti-framing headers, so embedding them in an iframe won't always work from a static HTML file — browsers block it for security. Use the Node server version (npm start) for a truly universal proxy. "Google search" shortcut uses igu=1 which Google normally allows to be framed.
